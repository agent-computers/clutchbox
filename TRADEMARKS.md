# Trademark policy

The code in this repository is licensed under [Apache-2.0](LICENSE), which lets you use, change, and redistribute it. The license doesn't cover the project's name and logos (its section 6 says so), and this policy explains how you may use them.

Agent Computers handles people's signed-in sessions. Its name has to mean code from this project, so that nobody installs a lookalike extension believing it is ours.

## The marks

- The name **Agent Computers**, alone or in other names ("Agent Computers Browser Sync").
- The lowercase italic **agent computers** wordmark and the italic **a** icon, including the extension's icons.

## Without asking

- **Say what's true.** Your product "works with Agent Computers", "uses `@agent-computers/playwright`", or "is built on Agent Computers". Articles, tutorials, talks, and comparisons may use the name and link to us.
- **Redistribute unmodified releases** under the name, such as the packages from npm or this repository's code as published.
- **Run it yourself.** Build and run the extension, the self-host server, and the packages for yourself or inside your organization, modified or not, keeping the name. That includes force-installing an extension built for your server across your company.
- **Keep the package names** in code: `@agent-computers/*` imports and dependencies are fine in a fork.

## Not without permission

- **Publish a modified extension under the name or icons**, on the Chrome Web Store or any other store or site. Give your build its own name and icon. A modified build can't use the name even if the change is small, because users can't tell what it changes.
- **Offer a hosted service named Agent Computers**, or one that suggests it is ours, endorsed by us, or an official edition.
- **Use the name in your product, company, or domain name**, such as `agentcomputers-sync.com` or "Agent Computers Pro". The same applies to social media accounts, npm scopes, and app or store listings.
- **Change the logos** or make ones that could be confused with them.

## Questions

To use a mark in a way not covered here, or to report a lookalike, especially an extension asking for cookie access under our name, open an issue or follow [SECURITY.md](SECURITY.md) for anything that puts users at risk.
